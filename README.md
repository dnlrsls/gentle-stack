# Gentle Stack

An open-source collection of reusable skills inspired by the core functionality of Gentle AI and Gentle Shell.

## Vision

Break down the main functionality of Gentle AI and Gentle Shell into focused, composable skills that coding agents can use to carry out development workflows.

Each skill should have a clear responsibility, explicit instructions, and the supporting resources needed to perform its task. The goal is to let developers adopt individual capabilities and combine them to suit their projects.

## Approach

- Identify the core capabilities and workflows in Gentle AI and Gentle Shell.
- Map each capability to a focused skill, documenting dependencies where needed.
- Write actionable instructions with clear inputs, expected outcomes, and validation steps.
- Include scripts, templates, or references when they help execute the workflow.
- Validate skills on real development tasks and improve them through community feedback.

## Project status

Gentle Stack is in its initial planning stage. The capability inventory, skill boundaries, and first implementations are still being defined. No skills have been implemented yet.

## Initial roadmap

- Inventory the main functionality of Gentle AI and Gentle Shell.
- Define the first set of skills and their responsibilities.
- Establish a consistent skill structure and documentation format.
- Implement and validate the first end-to-end workflow.
- Document installation, usage, composition, and contribution workflows.
