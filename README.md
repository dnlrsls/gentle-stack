# Gentle Stack

An open-source project inspired by Gentle AI and Gentle Shell, exploring a simpler way to work with AI and developer tools.

## Vision

Build an approachable foundation for AI-assisted development, with clear workflows, practical tooling, and a community-driven approach.

## Project status

Gentle Stack is in its initial planning stage. The architecture, technology stack, and first features are still being defined. There is no runnable application yet.

## Initial roadmap

- Define the project scope and core use cases.
- Choose the architecture and technology stack.
- Build a minimal working prototype.
- Document setup, usage, and contribution workflows.

## Contributing

Contributions and ideas are welcome. Open an issue to suggest a feature, report a problem, or discuss the project's direction. For substantial changes, please start a discussion in an issue before submitting a pull request.
